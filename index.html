Updating your data

This site has no database — your sales live in four plain CSV files. Two ways to update them:

1. Permanently (redeploy): export your order/sales history from each marketplace as CSV, replace the matching file in /data (poshmark.csv, mercari.csv, depop.csv, vinted.csv), keep the same column headers (or see README.md for the alias list this page recognizes), then redeploy on Netlify.

2. Preview only (this browser tab, right now): pick a platform and a CSV file below — it merges into the tables below without touching your deployed files. Refresh the page and it's gone.
